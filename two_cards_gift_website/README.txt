YOUR TWO-CARD GIFT WEBSITE

Files:
- index.html
- media/ (put your photos and voice notes here)

Add/rename your media to these exact names:
Men's Day photos:
  mens-day-1.jpg
  mens-day-2.jpg
  mens-day-3.jpg
Men's Day audio:
  mens-day-voice.mp3
Sorry photo:
  sorry-photo.jpg
Sorry audio:
  sorry-voice.mp3

You can use .png photos too, but if you do, change the matching filename in index.html.
Keep all media inside the media folder.

PUBLISH WITHOUT GITHUB:
1. Unzip this folder.
2. Put your 5 photos/audio files in the media folder using the exact names above.
3. Open https://app.netlify.com/drop and sign in.
4. Drag the WHOLE unzipped folder (the folder containing index.html and media) into Netlify Drop.
5. Wait for the deploy to finish. Use the public site URL Netlify gives you.

This is a static website. No npm, Git, or GitHub Actions required.
For public access, set the Netlify site's visitor visibility to Public.
